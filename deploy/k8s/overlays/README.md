# Kustomize Overlays

This directory contains environment-specific configurations for Massload deployments.

## Structure

```
overlays/
├── dev/          # Development environment
└── prod/         # Production environment (TODO)
```

## Usage

### Deploy to Development

```bash
kubectl apply -k deploy/k8s/overlays/dev/
```

### Deploy to Production

```bash
kubectl apply -k deploy/k8s/overlays/prod/
```

## Environment Configurations

### Dev (massload-dev.allfeat.org)

- Frontend: `https://massload-dev.allfeat.org`
- Backend API: `https://api.massload-dev.allfeat.org`
- Blockchain: `wss://node-dev.allfeat.io`

### Prod (massload.allfeat.io)

- Frontend: `https://massload.allfeat.io`
- Backend API: `https://api.massload.allfeat.io`
- Blockchain: `wss://node.allfeat.io`

## Important Notes

⚠️ **HTTPS Required**: The frontend MUST use HTTPS backend URL to avoid mixed content errors.

The `BACKEND_URL` is injected at runtime via `config.js` generated by the frontend container entrypoint.
